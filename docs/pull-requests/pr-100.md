# [PR 100](https://github.com/vig-os/sync-issues-action/pull/100) chore: adopt vigOS v0.3.5 devcontainer and upgrade Actions toolkit

## Description

Updates the project to the latest vigOS devcontainer (v0.3.5) and realigns the
tooling around Node. As part of the same effort, the GitHub Actions toolkit is
upgraded to its ESM-only releases (clearing bundled `undici` audit findings),
the committed `dist/` artifacts are narrowed to the shipped ncc bundle, and the
local `just test` workflow now runs the full suite. Closes the devcontainer
update task (#6).

## Changes Made

- **Devcontainer & developer workflow** (`.devcontainer/**`, `scripts/setup-node.sh`, `justfile`, `justfile.project`, `.cursor/**`, `.githooks/**`, `.pre-commit-config.yaml`)
  - Adopt vigOS v0.3.5 devcontainer; provision Node via `scripts/setup-node.sh` and `just` recipes
  - Run lint, build, and test inside the devcontainer; drop Python scaffolding and legacy `setup-env`/`build-dist` composite actions
- **GitHub Actions toolkit upgrade** (`package.json`, `package-lock.json`, `src/**`, `tsconfig.json`, `dist/**`)
  - Bump `@actions/github` to v9 (Octokit v7) and `@actions/core` to v3, clearing high-severity `undici` advisories
  - Update TypeScript module resolution and Jest module mocks for ESM-only toolkit packages
- **`dist/` tracking** (`.gitignore`, `dist/**`)
  - Track only the shipped ncc bundle (`dist/index.js`, `dist/licenses.txt`); stop committing tsc emit under `dist/src/`
- **Workflows, labels & docs** (`.github/workflows/**`, `.github/label-taxonomy.toml`, `docs/**`, `README.md`, `SECURITY.md`)
  - Adapt release/sync workflows and label taxonomy to the standardized vigOS layout
- **Local test runner** (`justfile.project`, `jest.config.js`)
  - `just test` runs the full suite (unit + integration when a token is available); add `just test-unit` for unit-only runs
- **Changelog** (`CHANGELOG.md`)
  - Document the above under the `Unreleased` section
