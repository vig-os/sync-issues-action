## Summary

The `@vercel/ncc` `^0.38.1 -> ^0.44.0` bump ([#126](https://github.com/vig-os/sync-issues-action/pull/126)) changed bundle output, but `dist/` was never regenerated. Per the documented design, `dev` is intentionally not dist-gated, so the drift first surfaced on the `release/0.4.0` -> `main` PR (#134) **Dist Check**, failing the 0.4.0 RC.
