# [PR 57](https://github.com/vig-os/sync-issues-action/pull/57) feat(ci): replace post-release workflow with PR-based main-to-dev sync

## Description

Replaces the old direct-push `post-release` dev sync with a protection-compliant PR-based `main` -> `dev` sync flow.

The new `sync-main-to-dev` workflow triggers on `push` to `main` and on `workflow_dispatch`, checks whether `dev` is behind, and only then creates a disposable sync branch and opens a PR into `dev`. Follow-up hardening in this PR addresses duplicate/no-op edge cases, expression correctness, branch cleanup completeness, and changelog tooling compatibility.

Good catch. The old workflow had some quirks with e.g. failed releases or continuous development in `dev` branch while a release process was ongoing. I switched to, upon release preparation, do:
1. Freeze unreleased section by renaming to `## X.Y.Z - T.B.D.`

_Posted on March 11, 2026 at 02:54 PM_

**Nit (non-blocking):** The `SYNC_BRANCH_PLACEHOLDER` find-and-replace in the conflict body (lines ~199–215) works but is a hand-rolled templating pattern that's easy to break silently. Two simpler alternatives:

1. **Unquoted heredoc** — use `<<BODY_EOF` instead of `<<'BODY_EOF'` so the shell expands `${SYNC_BRANCH}` directly. Safe here since the body contains no other `$` or backtick characters.

2. **`envsubst`** — keep the single-quoted heredoc but pipe through `envsubst '${SYNC_BRANCH}'`. Selectively expands only the listed variables. Available on all GitHub Actions runners (GNU gettext).

+            --search '"sync dev with main" in:title' \

+            --jq '[.[] | select((.headRefName | startswith("chore/sync-main-to-dev-")) or (.title | test("sync dev with main"; "i"))] | length')

The `--jq` filter used to count existing sync PRs has unbalanced parentheses/brackets (`select(...` is missing a closing `)` before the closing `]`). As written, `gh pr list` will fail and the workflow will stop before it can create the sync PR. Fix the jq expression so it’s valid JSON/JQ and returns a numeric count.
```suggestion
            --jq '[.[] | select((.headRefName | startswith("chore/sync-main-to-dev-")) or (.title | test("sync dev with main"; "i")))] | length')
```
