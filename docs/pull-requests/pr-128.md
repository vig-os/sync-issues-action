Closing this — TypeScript 7 can't land here yet.

I rebased this branch onto current `dev` and ran the full suite in the dev-shell. TypeScript 7.0 is the native Go rewrite (`tsgo`), which drops the JS compiler-internal APIs that our bundle/test/lint toolchain reaches into:

| Step | Result |
|------|--------|
| `tsc` | ✅ compiles clean |
| `npm install` | ❌ ERESOLVE — `typescript-eslint@8.64.0` peer-deps `typescript ">=4.8.4 <6.1.0"` |
| `npm run package` (ncc → `dist/`) | ❌ crash — `Cannot read properties of undefined (reading 'fileExists')` |
| `npm run lint` (typescript-eslint) | ❌ crash — `… (reading 'Cjs')` |
| `npm test` (ts-jest) | ❌ crash — `… (reading 'readFile')` |

Only bare `tsc` works — `@vercel/ncc`, `ts-jest`, and `typescript-eslint` all break. That's also why the `renovate/artifacts` check failed here (Renovate couldn't regenerate the lockfile for the same reason).

Tracked in #132; #133 pins `typescript` to `<7` in `renovate.json` so this stops being re-proposed until the toolchain supports TS 7.
