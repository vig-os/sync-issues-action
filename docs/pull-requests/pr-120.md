# [PR 120](https://github.com/vig-os/sync-issues-action/pull/120) feat: add format-command input for a user formatting hook

Implements the `format-command` design approved for #17 (chosen over a hook-script convention, a `run-pre-commit` boolean, and docs-only).

- New optional **`format-command`** input: a shell command the action runs on the synced files **after they are written and before outputs are set**, so the downstream commit step picks up formatted files.
- Every `{files}` placeholder is replaced with the shell-quoted modified paths (single-quote escaping covers spaces/metacharacters); a command without a placeholder runs as-is.
- Skipped when the input is empty or nothing changed; a failing command fails the action with `format-command failed: …` context.

TDD: failing spec committed first (6 new unit tests — placeholder substitution, quoting, skip conditions, error wrapping), then the implementation, then docs (`action.yml`, README inputs table, changelog) + rebuilt `dist/`. 121/121 tests, full hook suite green.
