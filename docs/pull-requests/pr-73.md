# [PR 73](https://github.com/vig-os/sync-issues-action/pull/73) chore(lint): upgrade ESLint toolchain to v10 and migrate flat config

## Description

Upgrade the lint toolchain as a coordinated change to resolve peer dependency conflicts and unblock CI for ESLint-related dependency updates.

This PR upgrades `eslint` to v10, aligns `@typescript-eslint` packages to v8, migrates to flat config with `eslint.config.mjs`, and closes the gap that broke superseded Dependabot PRs #63 and #67.

  - Upgraded `@typescript-eslint/eslint-plugin` to `^8.56.1`
  - Upgraded `@typescript-eslint/parser` to `^8.56.1`
