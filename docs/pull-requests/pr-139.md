## Seam migration

`release-extension.yml` gains an `attest` job (alongside the existing `verify-dist` backstop):

- **Runs** on final releases only (`if: ${{ inputs.release_kind == 'final' }}`) — mirrors the retired `attest-release.yml`, which existed to attest published final version tags; RC candidates publish disposable tags and are not attested.
- **Ordering** — `needs: [verify-dist]`, so provenance only ever attaches to a bundle already proven fresh at `finalize_sha` (the commit the published tag points at).
- **Permissions (exactly what it needs, within the ceiling)** — `contents: read`, `id-token: write`, `attestations: write`. **No `packages: write`** (nothing is published to a registry).
- **Mechanism** — `actions/attest@v4.1.1` with only `subject-path: dist/index.js` (same SLSA build-provenance predicate the prior workflow emitted, per #70), checking out `finalize_sha`.
- `attest-release.yml` (`push: tags: v*.*.*`) deleted.
