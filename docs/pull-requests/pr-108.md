# [PR 108](https://github.com/vig-os/sync-issues-action/pull/108) build(devkit): adopt vigOS devkit 1.3.0 in direnv mode

## Adopt vigOS devkit 1.3.0 (direnv) — replace the bespoke CI/release stack

Second consumer of the mode-aware devkit, following the commit-action pilot (vig-os/commit-action#32). Deployed off `dev` with the released `install.sh --version 1.3.0 --mode direnv --prune-devcontainer`.

### What changed
- **Devkit scaffold (direnv)**: Nix flake dev-shell (+`pkgs.nodejs`), `.envrc`, managed workflows/justfiles at 1.3.0; legacy `.devcontainer/` pruned. Tag scheme declared day one: `DEVKIT_TAG_PREFIX=v`, `DEVKIT_FLOATING_TAGS=major,minor`.
- **Flake-generated pre-commit hooks** (`hooks = { }`, `hooksExcludes = ["^dist/"]`): replaces the committed `.pre-commit-config.yaml` whose binary `typos` hook could not run on NixOS. `scripts/setup-node.sh` + `.node/` provisioning retired — node flows from the flake.
- **Crown jewels preserved**:
  - 8-scenario `integration-test.yml` matrix kept, wired to PRs via `integration-pr.yml` and to pushed tags via `published-tag-smoke.yml` (runs the action checked out AT the tag — consumer semantics).
  - **Provenance attestation** re-homed in `attest-release.yml` (tag push). ⚠️ Deviation from the plan: it cannot live in the `release-extension.yml` seam — the managed `release.yml` calls the seam under a `contents: read, packages: read` token ceiling and a called workflow can never elevate `GITHUB_TOKEN` (`id-token: write` would be denied). Devkit seam limitation to be filed upstream.
- **release-extension.yml re-purposed** as the dist-freshness release backstop (ported from commit-action): its old floating-tag mover is superseded by the managed promote's native `DEVKIT_FLOATING_TAGS` job.
- **Ported gates**: `dist-check.yml` (Dist Check, PRs to release/**+main), `js-quality.yml` (eslint + prettier via `just`).
- **codeql.yml push paths hand-patched to TS** — devkit renders only the language matrix; upstream fix tracked in vig-os/devkit#1142 (re-apply after every upgrade until fixed).
- **Retired**: `security-scan.yml` (pure placeholder), `CODEOWNERS`, `prepare_changelog.py` + `release_helpers.sh` + their tests, `resolve-image` composite.
- `package.json`: add `bundle` alias (devkit-standard name driving `just bundle` and release-core's native dist prep) and `format:check`.

### Verification (local, NixOS, direnv)
- `nix develop` resolves: node v24.16.0, npm 11.13.0, just, prek; flake-generated pre-commit config self-installs.
- `just sync / lint / format-check / build / bundle` green; **115 jest tests pass**; `dist/` clean after rebuild (bundle fresh).
- **Full prek suite green — including `typos`, now flake-sourced** (the pilot's NixOS fix, reproduced here).
- `actionlint` clean across all workflows.
